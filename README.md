# Hobart Historic Walking Trails - Refined High-Fidelity Prototype

This React/Vite prototype demonstrates the selected KIT519 Assignment 2 workflow.

## Recommended presentation path

1. Explore a heritage place.
2. Open Map, select a route and use **Add Stop**.
3. Continue and choose **Standard Map** or **AR Navigation**.
4. In AR Navigation, use **Simulate Arrival**, then **Scan Building**.
5. Tap the scanning control to recognise the landmark.
6. Drag the **Information**, **Audio Guide**, and **Historical Video** bubbles.
7. Open Audio to demonstrate play/stop narration and subtitles.
8. Use **Print / Export** to show the printable notes pack.

## Run locally

Use `pnpm install` followed by `pnpm dev`. A production build has been verified with `pnpm run build`.

The camera, mapping, recognition, audio, video, PDF export and printing behaviours are simulated for prototype evaluation; they are not production integrations.
